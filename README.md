# Secure Game Engine

Windows向けにC++20とDirectX 12で開発しているゲームエンジンです。個人・少人数のゲーム開発者が、必要な機能と防御を選んで利用できる構成を目指しています。汎用の完成済みSDKではなく、開発・検証中のプロジェクトです。

## ゲーム

- [FPS](docs/games/fps.md)：移動、射撃、敵、遮蔽物、被弾、再開。
- [かくれんぼ](docs/games/hide-and-seek.md)：隠れた対象を探すゲーム。
- [カード](docs/games/card.md)：4人ババ抜き。ローカル対戦とRustサーバーを用いたオンライン構成。
- [共通射撃場](docs/games/shooting-range.md)：自作版とUnity版でルールと入力を比較するためのゲーム。

## 主な機能と検証

DirectX 12描画、影、PBR、アニメーション、選択式Jolt物理、レイトレーシング経路、音声、通信を実装しています。機能を選択して制作サンプルを構成できます。DXR対応GPUでの描画成功は未検証です。

防御はshuffle、watchdog、depth-guard、tag-maskを個別に選択できます。カードのオンライン構成ではRustサーバーがルールを管理し、各プレイヤーに必要な情報だけをTLSで送ります。これらがあらゆる改変を防ぐことを示すものではありません。

共通射撃場の実行状態はUnity版と入力を合わせて照合しました。署名付き全4モードと射撃場専用構成の比較では、同じ射撃場を各30回実行し、配布量が96.8%減少、プロセス起動から最初の更新までの時間の中央値が444.4msから416.9msとなりました。測定条件に依存し、入力遅延やGPU時間を示すものではありません。実パッドでの比較、別PC検証、統合デモの制御条件を揃えた性能測定は未完了です。

## 構成

- `engine/`：描画・入力・物理・音声・通信などの共通機能
- `game/`：ゲームの実装
- `assets/`：シェーダーと公開可能なモデル。外部所有モデルは含みません
- `server_rs/`：カードサーバー
- `tools/`：ビルド・モデル変換・試験・計測
- `comparison/`：Unity版の共通射撃場と比較データ
- `third_party/`：外部ライブラリとそれぞれのライセンス

## ビルド

Windows x64、Visual Studio C++開発ツール、Windows SDK、CMake 3.20以上、DirectX Shader Compilerが必要です。PowerShellで以下を実行します。

```powershell
./tools/build.ps1 -Profile range
```

`fps`、`all`も選択できます。外部所有素材は含まないため、元の開発環境と見た目が異なる場合があります。
